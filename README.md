**Cars-acceptability-analysis**

*Overview*

Data analysis and visualization of car acceptability using python,pandas,seaborn and matplotlib.
Data cleaning and visualization was perform to bring out  meaniful values.
The Random Forest model yields robust performance across all evaluation metrics on unseen testing partitions.
Accuracy: 97.40%
Precision / Recall / F1-Score: Well-balanced across both majority (unacc) and minority classes (vgood, good), 
proving the pipeline's stability against class imbalance.

*Data Features*

- Buying Price
- Maintaining Cost
- Numbers of Doors
- Seating Capacity
- Loggage Boot Size
- Safety Rating
- Car Aceptability (Target Varieble)

- *Objectives*

- Explore relationships between vehicle attributes and acceptability
- Identify the most influential factors affecting cars evaluation
- Visualise patterns and trends within the dataset
- Prepare the data for machine learning classification models

- *Tools*

- Python
- PandaS
- Numpy
- Seaborn
- Matplotlib
- Jupiter Notebook

- *Key Insight*

- Vehicle safety,Cost,and Capacity play significant roles in determined the overall car
- acceptability,making the dataset a valueble resource for classification and predictive
- modeling
